Halo: the Argus suite as Terraform

argus-halo deploys the full Argus suite as a public, read-only stack: two Hetzner hosts split public and private, behind Cloudflare, with state in HCP Terraform. It's sized to cost about €11 a month.

The stack isn't running at the moment. The live demos on dragonhound.dev are static sites.

Architecture

Cloudflare

Hides the origin, enforces strict TLS, rate-limits the paths that cost money.

↓ HTTPS

Demo host: public, disposable

Caddy, Studio, and lens, curator, quarry, forge, proof and atlas from pinned images. All read-only.

↕ private network

Core host: no public data ports

Postgres, Qdrant and Silo, with Prometheus and Grafana. SSH and Grafana answer one admin address.

↑ restored on first boot

R2: the recorded run

GPU work runs once on local hardware. The hosts replay its output.

What it demonstrates

  • Tests that need no credentials

    terraform test plans the whole configuration against mocked providers and asserts firewall, TLS, DNS and rate-limit properties.

  • Failing at plan time

    A postcondition checks the server type against live Hetzner stock and lists what is available, before anything is created.

  • Refusing dangerous input

    An admin address of 0.0.0.0/0 doesn't pass validation.

  • Updates without replacing hosts

    Changing user_data forces a new server, so it carries only config and a fetcher. Service versions and routes update in place.

  • Guarding what can't be rebuilt cheaply

    prevent_destroy on the R2 bucket makes a routine terraform destroy refuse.

  • Checks validate can't do

    Templates are rendered, then routes, rate limits, environment, image pins and read-only settings are checked against each other.

  • A proven attack surface

    A smoke test boots the demo tier from its real compose file and pins, then checks what it refuses: GPU work, writes, path traversal and cross-site requests.

Try it without an account

git clone https://github.com/smk762/argus-halo
cd argus-halo
make test       # terraform test, mocked providers
make validate   # templates, routes, pins, fmt, validate
make smoke      # boot the demo tier in Docker and probe it
